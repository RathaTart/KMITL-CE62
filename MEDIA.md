## Media that was intentionally not copied

Several recordings in the source folders are larger than GitHub's 100 MB single-file limit, and many other videos, datasets, model weights, VM images, and archives are not useful in a source-first portfolio. The README therefore links only the compact final game demo and uses still images for the other projects.
