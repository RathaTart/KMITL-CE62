# เพิ่มตัวตรวจลักษณะก่อนคืนมาสก์

## ผลหลัก

**ลดการเลือกเมื่อคำอธิบายไม่ตรงได้ แต่หมวกยังมีข้อแลกเปลี่ยนเรื่องคนที่พลาด** ไม่มีการฝึกน้ำหนัก CoHD หรือ CLIP ใหม่ ใช้ภาพเดิม 6 ภาพปรับเกณฑ์ แล้วล็อกวิธีก่อนทดสอบ 24 ภาพใหม่ที่ไม่ซ้ำบุคคลเดิม รวม 40 คำสั่งที่ลักษณะชัดเจน

| สิ่งที่วัดบนภาพใหม่ | CoHD เดิม | Scale704 | เพิ่มตัวตรวจ |
|---|---:|---:|---:|
| มีหมวกจริง → คืนมาสก์ | 9/9 | 9/9 | 7/9 |
| ไม่มีหมวก → ปฏิเสธถูก | 0/13 | 0/13 | 9/13 |
| เสื้อคลุมดำจริง → คืนมาสก์ | 6/6 | 6/6 | 6/6 |
| ไม่ใช่เสื้อคลุมดำ → ปฏิเสธถูก | 0/12 | 0/12 | 12/12 |
| ตรงคำสั่งทั้งหมด → คืนมาสก์ | 15/15 | 15/15 | 13/15 |
| ไม่ตรงทั้งหมด → ปฏิเสธถูก | 0/25 | 0/25 | 21/25 |
| เวลาเฉลี่ยต่อคำขอ ขณะ GPU ใช้งานร่วม | 1.418 วินาที | 1.299 วินาที | 1.360 วินาที |

เพิ่มเวลาจาก Scale704 ประมาณ 0.061 วินาทีต่อคำขอ หรือประมาณ 4.7% ในรอบนี้ แต่ยังเร็วกว่า CoHD เดิมที่รันในรอบเดียวกัน ไม่ใช่การรับรองเวลาเมื่อ GPU ว่าง ตัวเลขนี้ห้ามนำไปเทียบตรง ๆ กับเวลา 0.593/0.654 วินาทีในรอบเก่า

สำหรับภาพเต็ม 2 ภาพ × 2 ลักษณะ ซึ่งตรวจหลายกล่อง เวลาเฉลี่ยเป็น 1.447 วินาที CoHD เดิม, 1.298 วินาที Scale704 และ 1.519 วินาทีเมื่อเพิ่มตัวตรวจ: เพิ่มประมาณ 17.0% จาก Scale704 ไม่ใช่ 4.7% แบบภาพครอป ผลภาพเต็มยังไม่มี appearance GT จึงเป็นเพียงการทดสอบการทำงานและเวลา

คำสั่งไม่ตรงแต่ยังเลือก ลดจาก 25 → 4 กรณี ส่วนคนที่ควรเลือกแต่พลาด เพิ่มจาก 0 → 2 กรณี ทั้งสองเป็นหมวก จึง **ยังไม่ผ่านเป้าหมายดีขึ้นโดยไม่พลาดคนเพิ่ม** เก็บ CoHD เดิมเป็นค่าเริ่มต้น และตัวตรวจเป็นทางเลือกทดลอง

## เพิ่มอะไร

1. Scale704 ใช้คำสั่ง `all people` สร้างมาสก์คนที่เป็นไปได้
2. แบ่งบริเวณต่อเนื่องเป็นกล่องโดยประมาณ สำหรับภาพครอปใช้กล่องที่มีพื้นที่มากที่สุด; ภาพเต็มทดลองได้สูงสุด 8 กล่อง
3. ใช้ CLIP ViT-B/32 ที่ตรึงน้ำหนัก เทียบภาพคนกับข้อความลักษณะที่ตรงและไม่ตรง
4. หมวกใช้ภาพคนทั้งตัว ส่วนเสื้อดำใช้ช่วงลำตัว 20–75% ของความสูงกล่อง
5. เก็บมาสก์เมื่อคะแนนผ่านเกณฑ์ ไม่ผ่านจึงคืนว่าง

ลองส่วนศีรษะบนสุด 42% ด้วย แต่ในชุดพัฒนา 6 ภาพ ผลด้อยกว่าดูคนทั้งตัว สำหรับเสื้อดำ ดูลำตัวและทั้งตัวได้คะแนนเท่ากันที่เกณฑ์ที่เลือก จึง **ยังไม่ได้พิสูจน์ว่าครอปลำตัวเหนือกว่า** การเลือกใช้ลำตัวเป็นกฎตัดสินกรณีเสมอที่กำหนดไว้

ส่วนที่ปรับคือเกณฑ์และการเลือกบริเวณจากชุดพัฒนา ไม่ได้ปรับน้ำหนักโมเดล ใช้ threshold grid −0.02, −0.01, 0, 0.01, 0.02 เลือกหมวก margin >0 และเสื้อดำ >−0.01 คะแนนเป็นความต่างของ cosine similarity ไม่ใช่ความน่าจะเป็นความถูกต้อง

## ข้อจำกัดของหลักฐาน

- คะแนนวัดเพียงการคืนมาสก์ว่าง/ไม่ว่างให้ตรงกับลักษณะของคนหลัก ไม่ใช่ Mask IoU หรือความแม่นยำเลือกบุคคลจากฝูงชน
- RSTPReid เป็นภาพครอปจากกล้องวงจรปิด ไม่มี native mask/absence GT สำหรับคำสั่งใหม่ ใช้คำบรรยายร่วมกับการตรวจภาพโดยผู้ช่วย AI ก่อนรัน ไม่ใช่ป้ายกำกับที่มนุษย์อิสระรับรอง
- คัดจาก 32 ภาพตัวเลือกเป็น 24 ภาพ เก็บคำตอบลักษณะก้ำกึ่งเป็น null และไม่คิดคะแนนคำสั่งนั้น จึงเป็น diagnostic ที่คัดเลือก ไม่ใช่ตัวแทนทั้งชุด และไม่รวมฮู้ดที่กำกวมกับหมวก
- บุคคลไม่ซ้ำชุดพัฒนา แต่ยังไม่ใช่กล้องใหม่ และยังไม่ตัดข้อมูลซ้ำกับ pretraining
- รองรับเพียงหมวกและเสื้อคลุม/เสื้อด้านบนสีดำ ไม่ใช่การเข้าใจคำบรรยายทั่วไปหรือคำสั่งหลายเงื่อนไข
- กล่องมาจากส่วนต่อเนื่องของมาสก์ ไม่ใช่ instance detector คนติดกันอาจถูกรวม คนที่ขั้นแรกหาไม่พบจะกู้กลับด้วยตัวตรวจนี้ไม่ได้
- ภาพเต็ม CCTV 2 ภาพเดิม ทดลองทั้งสองลักษณะในโหมดหลายกล่องไว้ดูภาพเท่านั้น ไม่มี appearance GT จึงไม่รายงานคะแนนเลือกถูกคน
- วัดเวลารวมอ่านภาพ เตรียมภาพ CoHD ครอป CLIP ตัดสิน และคืนมาสก์ เมื่อโมเดลโหลดแล้ว ไม่รวมโหลดโมเดล/วาดภาพ/ประเมิน เก็บ text embeddings ของคำลักษณะคงที่ไว้ตั้งแต่เริ่ม แต่ไม่เก็บ image features ข้ามคำขอ
- มีงานฝึกอื่นใช้ GPU ตลอดรอบ ไม่หยุดหรือแก้งานนั้น เปรียบเทียบ latency ได้เพียงเชิงสังเกตภายใต้โหลดครั้งนี้

## ข้อสรุปเพื่อพัฒนาต่อ

ตัวตรวจเสื้อดำให้สัญญาณที่ดีในตัวอย่างเล็กนี้ หมวกยังต้องลดการปฏิเสธคนที่ใส่หมวกจริง ควรทำ human annotation ของตัวอย่างที่กำกวมและภาพเต็ม แยกชุดใหม่ก่อนทดสอบรอบถัดไป และทดสอบการตอบไม่แน่ใจแทนการบังคับรับ/ปฏิเสธ การทดลองนี้ไม่ใช่สถาปัตยกรรมใหม่ที่พิสูจน์ความเหนือกว่าแล้ว

ภาพกรณี `08_hat` แสดงสาเหตุที่ควรแก้ต่อ: กล่องที่ได้จากมาสก์ `all people` เริ่มต่ำกว่าหมวก ทำให้แม้เลือกตรวจทั้งกล่องก็ไม่ได้เห็นหมวกครบ ควรทดลองขยายด้านบนของกล่องหรือใช้กล่องจาก detector แยกต่างหากในรอบใหม่ ไม่ปรับแล้วนำคะแนนชุดนี้มาอ้างว่าเป็นผลที่ไม่เคยเห็น

อ้างอิง [CLIP](https://github.com/openai/CLIP), [checkpoint ViT-B/32](https://huggingface.co/openai/clip-vit-base-patch32), [RSTPReid](https://github.com/NjtechCVLab/RSTPReid-Dataset)
