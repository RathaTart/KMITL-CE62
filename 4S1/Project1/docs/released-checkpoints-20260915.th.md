# ผลทดสอบ checkpoint ที่เผยแพร่: SSP-SAM และ CoHD-Tiny

ทดสอบครบ 90 ภาพบนเครื่อง cenara70hx (NVIDIA CMP 70HX, VRAM 8 GB) โดยไม่ฝึกเพิ่ม ชุดนี้คือ 90 ภาพจากการทดลอง router ที่นำกลับมาใช้เปรียบเทียบเบื้องต้น ไม่ใช่ชุดใหม่ที่ยังไม่เคยตรวจผล

| วิธี | IoU ภาพที่มีเป้าหมาย 60 ภาพ | ตอบไม่มีเป้าหมายถูก 30 ภาพ | เวลารันโมเดล/ภาพ |
|---|---:|---:|---:|
| LISA + cache | 73.07% | 0.00% | 13.753 วินาที |
| SSP-SAM-224 (AMP ที่แก้แล้ว) | 75.51% | 33.33% | 5.378 วินาที |
| CoHD-Tiny | 78.01% | 20.00% | 0.637 วินาที |

CoHD-Tiny มี IoU ของภาพที่มีเป้าหมายสูงที่สุดในตัวอย่างนี้ และเร็วกว่าเวลาขั้นโมเดลของ LISA ที่บันทึกไว้ประมาณ 21.6 เท่า ส่วน SSP-SAM เร็วประมาณ 2.6 เท่า และตอบกรณีไม่มีเป้าหมายได้ดีกว่า CoHD ทั้งสามวิธีให้หน้ากากไม่ว่างครบ 60 ภาพที่มีเป้าหมาย แต่การตรวจกรณีไม่มีเป้าหมายยังไม่ดีพอ: SSP-SAM ตอบถูก 10/30 และ CoHD 6/30

ความต่าง positive IoU จาก LISA คือ CoHD +4.95 จุดเปอร์เซ็นต์ (ช่วง bootstrap 95%: −0.58 ถึง +10.83) และ SSP-SAM +2.45 จุดเปอร์เซ็นต์ (−4.38 ถึง +9.42) ทั้งสองช่วงคร่อมศูนย์ จึงยังยืนยันการเพิ่มความแม่นยำทางสถิติไม่ได้บนชุดขนาดเล็กนี้ คะแนน balanced ซึ่งเฉลี่ย positive IoU กับความถูกต้องกรณีไม่มีเป้าหมายคือ SSP-SAM 54.42%, CoHD 49.01%, LISA 36.53% และไม่ควรเรียกคะแนนนี้ว่าความแม่นยำการแบ่งส่วนคน

ใช้ checkpoint gRefCOCO จากผู้เขียนของ [SSP-SAM](https://github.com/WayneTomas/SSP-SAM) และ [CoHD](https://github.com/RobertLuo1/CoHD) ตรวจ SHA256 ของไฟล์น้ำหนักและบันทึก commit โค้ด วิธีใหม่ทั้งคู่ฝึกเฉพาะ gRefCOCO มาแล้ว ขณะที่ LISA ของเรายังไม่ได้ fine-tune แบบเดียวกัน ผลจึงเปรียบเทียบ checkpoint ที่ใช้งานจริง ไม่ได้แยกผลของสถาปัตยกรรมอย่างเดียว และไม่ยืนยันว่าไม่มีข้อมูลซ้ำกับ pretraining หรือใช้ได้ดีบน CCTV

การวัด SSP-SAM รวมการคำนวณ SAM image embedding ใหม่ทุกภาพ ไม่ใช้เฉพาะเวลา decoder ที่รับ embedding สำเร็จรูป การแปลง SAM ทั้งตัวเป็น half ในรอบแรกทำให้คุณภาพผิดปกติ จึงเก็บรอบนั้นเป็นหลักฐานวิเคราะห์เท่านั้น รุ่นสุดท้ายเก็บน้ำหนัก float32 และเปิด autocast เฉพาะ image encoder ตรวจเทียบ full float32 บนสามภาพแล้วต่าง 0, 0 และ 1 พิกเซล แต่ไม่ถือว่าเท่ากันทุกภาพโดยสมบูรณ์ ไม่มีการเปลี่ยน checkpoint สถาปัตยกรรม ข้อความ หรือ threshold ตามผลทดสอบ

CoHD ใช้ PyTorch deformable-attention fallback ที่ผู้เขียนเตรียมไว้บน GPU เพราะเครื่องไม่มี CUDA toolkit สำหรับ compile เวลาจึงเป็นของ backend นี้โดยเฉพาะ หน้ากากทั้งสองวิธีใช้กฎของผู้เขียนและแปลงกลับขนาดภาพต้นฉบับเพื่อเทียบกัน กฎไม่มีเป้าหมายของ SSP-SAM คือหน้ากาก native 512×512 มี foreground น้อยกว่า 50 พิกเซล ส่วน CoHD ใช้ no-target class argmax

เวลาขั้นโมเดล synchronize GPU และไม่รวมโหลดโมเดลครั้งแรก เวลาต่อคำขอที่รวมอ่านภาพ เตรียมข้อมูล และบันทึกหน้ากากคือ SSP-SAM 5.417 วินาที และ CoHD 0.646 วินาที เวลา LISA เป็นผลที่บันทึกไว้จากรอบก่อนบน GPU เดียวกัน ไม่ใช่การจับเวลาสลับกันในรอบนี้ ระหว่างรันมีงานอื่นใช้ GPU จึงรอโดยไม่หยุดงานนั้น

แนะนำใช้ **CoHD-Tiny เป็น baseline หลักตัวถัดไป** และเก็บ SSP-SAM เป็นคู่เทียบด้านกรณีไม่มีเป้าหมาย ควรทดสอบชุดใหม่ที่สงวนไว้และมีขนาดใหญ่ขึ้นก่อนอ้างว่าเหนือกว่าโดยทั่วไป การนำ checkpoint งานวิจัยที่เผยแพร่มารันเป็นการปรับปรุง baseline ไม่ใช่สิ่งประดิษฐ์ใหม่ของเรา

ผลและหน้ากากทั้งหมดอยู่ใน `code/results/released_checkpoints_20260915` รุ่น SSP สุดท้ายใช้ชื่อ `SSP_SAM_224_AMP` ห้ามนำรอบ `SSP_SAM_224` ที่แปลงทั้งตัวเป็น half มาแทนผลสุดท้าย รายละเอียดการทำซ้ำและข้อจำกัดครบถ้วนอยู่ใน `docs/released-checkpoints-20260915.md` ภาพตัวอย่างเลือกภาพแรกของแต่ละประเภทจาก manifest โดยไม่ดูคะแนน และตรวจการจัดแนวหน้ากากด้วยสายตาแล้ว
